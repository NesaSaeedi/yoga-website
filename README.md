# 🧘‍♀️ Yoga Website

A modern and calming **Yoga Website** designed and developed from scratch using HTML and CSS.

## 🌐 Live Demo

👉 **[View Live Website]( https://nesasaeedi.github.io/yoga-website/)**

## 🌿 About The Project

This project is a front-end website focused on yoga, relaxation, and a healthy lifestyle. The design aims to create a peaceful and welcoming experience through a clean layout, soft visual elements, and an organized user interface.

The project was created as a practical exercise to improve web design and front-end development skills.

## ✨ Features

* 🏠 Clean and welcoming homepage
* 🧘‍♀️ Yoga-focused content and sections
* 🌱 Calm and minimal visual design
* 🎨 Custom CSS styling
* 📱 Structured page layout
* 🖼️ Image-based visual sections
* 🔗 Easy navigation between sections

## 🛠️ Built With

* HTML5
* CSS3

## 🎯 Project Goals

This project was created to practice and improve:

* HTML page structure
* CSS styling and layouts
* Flexbox
* Typography
* Spacing and alignment
* Color selection
* Visual hierarchy
* Responsive web design concepts
* Front-end UI design
